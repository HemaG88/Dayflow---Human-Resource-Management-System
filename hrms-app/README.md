# Dayflow — Human Resource Management System

##  Overview

Dayflow is a lightweight Human Resource Management System designed to simplify employee management, attendance tracking, leave management, and employee profile management.

The application provides a centralized interface for managing employee information and daily HR operations.

## Project Demo

https://www.image2url.com/r2/default/videos/1787401818372-83567950-626d-4753-9bc0-8a9081fa646f.mp4

##  Features

- Employee management
- Employee search
- Employee profiles
- Check-in / Check-out
- Attendance tracking
- Attendance status indicators
- Leave management
- Profile management
- Admin and employee roles
- LocalStorage-based data persistence
- Responsive interface

##  Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

##  Attendance

The Attendance module provides:

- Employee attendance records
- Check-in time
- Check-out time
- Working hours
- Extra hours
- Employee search
- Date-based attendance view
- Mark Present functionality

##  Employee Management

The Employees page provides:

- Employee cards
- Employee ID
- Name
- Email
- Role
- Search functionality
- Check-in / Check-out controls
- Employee profile navigation

##  Data Storage

The application uses browser LocalStorage for client-side persistence.

Storage keys include:

- `hrms_current`
- `hrms_view`
- `hrms_users`
- `hrms_attendance`
- `hrms_timeoff`
